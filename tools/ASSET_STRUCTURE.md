# Asset structure

## Objectif

Eviter le dossier image plat.

## Organisation

- assets/img/home : home
- assets/img/music : violon, live, enregistrements
- assets/img/projects : scores, films, scene
- assets/img/gallery : portraits, acting, model
- assets/img/contact : booking, contact
- assets/img/press : press kit / CV
- assets/img/placeholders : assets temporaires
- assets/img/source : fichiers sources fournis
