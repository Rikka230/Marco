# Marco Charlas-Hou - Cover Site Prototype

Prototype HTML/CSS/JS vanilla pour Marco Charlas-Hou.

## Lancer en local

```bash
python -m http.server 5173
```

Puis ouvrir :

```text
http://localhost:5173
```
